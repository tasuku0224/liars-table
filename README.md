# ライアーズ・テーブル 第1巻『嘘つきの円卓』 公式特設サイト

小説『ライアーズ・テーブル 第1巻『嘘つきの円卓』』（著者：ほろ つばさ）の特設サイトです。

公開URL: https://tasuku0224.github.io/liars-table/

## 構成

- `index.html` — ページ本体（ファーストビュー／黒塗り資料／円卓の八人／プロローグ試し読み／各ストアへの導線）
- `assets/style.css` — 配色（濃紺 #070a12〜#0d1324、金 #d4af6a、真紅 #d9383a、オフホワイト #eae6dc）とレイアウト
- `assets/main.js` — 導入演出、円卓の八人の切り替え、ノイズ波形メーター、黒塗りの解除

## ローカルで確認する

静的サイトなので、任意のHTTPサーバーで `index.html` を配信すれば表示できます。

```sh
python3 -m http.server 8000
```
